
# CallBooking — План развития

## Цель

Развитие пользовательского опыта сервиса бронирования встреч.

В рамках второго проекта Hexlet запланированы одна новая возможность и исправление одной обнаруженной ошибки. Задачи будут использоваться для отработки агентного процесса разработки через GitHub Issues и Pull Requests.

## 1. Запланированные возможности (Features)

### FEAT-01: Отображение времени в часовом поясе пользователя

**Проблема**

Сейчас время доступных слотов, предстоящих встреч и подтверждённых бронирований отображается в UTC (`UTC+00:00`).

Пользователям из других часовых поясов приходится самостоятельно пересчитывать время, что неудобно и может привести к ошибкам при записи.

**Ожидаемое поведение**

- Пользователь видит время встреч в своём часовом поясе.
- Часовой пояс отображаемого времени понятен пользователю.
- Время отображается согласованно на страницах выбора слота, подтверждения бронирования и предстоящих событий.
- Изменение способа отображения времени не влияет на фактическое время бронирования.

## 2. Известные ошибки (Bugs)

### BUG-01: Сброс данных формы при переключении временного слота

**Проблема**

При выборе другого доступного временного слота введённые пользователем имя и email сбрасываются. Пользователю приходится заполнять форму повторно.

**Шаги воспроизведения**

1. Открыть страницу записи на встречу.
2. Выбрать доступный временной слот.
3. Заполнить поля «Имя» и «Email».
4. Выбрать другой доступный временной слот.

**Фактическое поведение**

Поля «Имя» и «Email» очищаются.

**Ожидаемое поведение**

- Ранее введённые имя и email сохраняются при выборе другого слота.
- Пользователь может изменить время встречи без повторного заполнения контактных данных.
